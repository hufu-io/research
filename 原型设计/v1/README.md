# HuFu 移动端交互原型 v1

本原型依据 `docs/current-version.md`、`docs/ui-redesign.md` 和 `DESIGN.md` 制作，使用原生 HTML、CSS 和 JavaScript，无运行时依赖。

本版本使用的字体、图片和图标统一放在当前目录的 `assets/` 中，不依赖仓库根目录的公共资源。

## 原型定位

原型用于说明功能范围和交互逻辑，不作为最终 UI 的排版依据。后续原型页面可以通过连线、编号和便签补充以下信息：

- 点击入口与目标页面
- 弹层、返回和中断规则
- 加载、空数据、失败、禁用与完成状态
- 网络、账户和钱包上下文变化
- 签名、授权、跨链及资产操作的安全确认点

正式视觉方案位于 `../../UI&UX/v1/`，只继承原型的功能目标和约束，页面布局与视觉表现独立设计。

## 预览方式

在 `research-doc` 根目录启动静态服务器：

```bash
python3 -m http.server 4174
```

访问：

```text
http://127.0.0.1:4174/原型设计/v1/
```

## 已覆盖流程

- 首页、社交、市场、发现、我的五个一级 Tab
- FullOn、Ethereum、Solana 钱包与页面上下文同步
- 正常、无资产、无钱包和信息加载失败四种首页演示状态
- 转账填写、核对和模拟结果
- 收款二维码、交易记录和扫码解析
- FLON、SING、BTC、ETH 等行情详情和近期成交
- DApp 官方域名、所需网络和网络不匹配确认
- FullBridge 跨链参数、费用、预计到账和状态追踪
- 身份安全、RWID 提示和本地钱包昵称编辑
- Aime 半屏、完整对话、最小化、关闭和本地开关持久化

## 原型边界

- 所有行情、余额、地址和交易记录均为演示数据
- 不连接真实钱包、DApp 或网络接口
- 不请求助记词、私钥、短信验证码或真实签名
- 转账、授权和跨链只演示信息核对，不提交链上交易
