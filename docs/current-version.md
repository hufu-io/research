# HuFu 现有版本功能介绍

> 本文描述 HuFu 当前版本的产品定位、主要界面和已有功能。计划中的 UI 调整与新增交互请参阅 [HuFu App 改版设计](./ui-redesign.md)。

## 产品定位

HuFu 是一款集去中心化自托管多链钱包、Web3 社交、数字资产市场、DApp 发现与 AI 智能体于一体的移动 App。

用户通过本地钱包管理数字资产，并以钱包账户作为用户身份标识进入 HuFu 社交及 FullOn Network 生态。

## 当前底部导航

现有版本的底部导航包含五个一级 Tab：

| Tab | 主要功能 |
| --- | --- |
| 社交 | 钱包身份登录、1:1 聊天、群聊及聊天室工具 |
| 市场 | 主流数字货币与生态币行情、走势图和市场资讯 |
| AI | Aime 智能体问答、FullOn 生态介绍和 DApp 推荐 |
| 发现 | FullOn 及其他知名公链的 DApp 入口 |
| 钱包 | FullOn 及其他受支持公链的钱包和资产管理 |

## 自托管多链钱包

HuFu 是一款去中心化自托管钱包，用户自主掌管钱包密钥和数字资产。

HuFu 以 FullOn Network Blockchain 为基础公链，同时支持多条知名公链，包括但不限于：

- FullOn Network
- Bitcoin（BTC）
- Ethereum（ETH）
- Solana（SOL）
- BNB Smart Chain（BNB/BSC）
- Tron Network（TRX）
- 其他受支持网络

钱包模块用于管理账户、数字资产、收款、转账和交易记录等信息。

## Web3 社交

用户通过本地钱包签名，以钱包身份登录 HuFu 社交服务，并建立与钱包账户名对应的社交身份。

社交模块包括：

- 用户之间一对一聊天
- 创建、加入和管理群聊
- 消息和会话管理
- 数字红包等聊天室 Web3 工具
- 展示曾经访问过的 DApp，便于从聊天室快速再次打开

涉及红包、转账或 DApp 的资产操作仍需由用户通过本地钱包确认和签名。

## 数字资产市场

市场模块用于展示数字资产公开行情，包括：

- 主流数字货币价格与涨跌幅
- FullOn 平台生态币行情
- 不同周期的价格走势图
- 交易对和公开成交信息
- 市场快讯与 FullOn 生态动态

HuFu 展示行情和公开链上数据，不在行情页面内直接提供交易撮合或资产托管服务。

## Aime 智能体

Aime 是 HuFu 当前版本底部导航中的独立 AI Tab，可以：

- 回答 FullOn Network Protocol 相关问题
- 介绍 FullOn 公链及 DApp 应用生态
- 解答常见 Web3、钱包和多链使用问题
- 根据用户需求推荐合适的 DApp
- 引导用户进入相应 DApp

Aime 提供信息和操作引导，不代替用户完成钱包授权、签名、转账、兑换或跨链。

## DApp 发现

发现模块汇集 FullOn Network 及多条知名公链的生态应用入口，覆盖：

- 数字红包
- 跨链
- 借贷
- 质押
- 锁仓
- 去中心化交易
- RWA（现实世界资产）
- 其他 Web3 应用

FullOn 生态中的重点 DApp 包括：

- [FullSwap](https://fullswap.flon.network)：去中心化兑换和流动性市场
- [FullBridge](https://fullbridge.flon.network)：FullOn 与其他受支持网络之间的跨链入口

## RWID 账户恢复能力

FullOn 特有的 RWID 技术允许用户绑定手机号。当本地私钥因设备丢失、损坏或误删而无法使用时，用户可以完成短信验证码校验，授权将账户换绑至新的公钥，从而恢复对原账户及链上资产的控制权。

RWID 恢复的是账户控制权，不会找回或导出已经丢失的旧私钥。
