# HuFu App 改版设计

> 本文描述 HuFu App 的目标信息架构、页面模块和关键交互。当前已上线功能请参阅 [HuFu 现有版本功能介绍](./current-version.md)。

## 改版目标

本次改版旨在降低 Web3 钱包的使用门槛，让用户更容易地创建和识别钱包账户、保护及恢复账户、查看持仓相关行情，并发现所需的 FullOn 生态 DApp。

重点包括：

- 新增聚合首页，突出当前链、当前账户、重点功能、DApp、行情与快讯
- 简化钱包初始化和账户生成流程
- 支持为每个钱包账户设置仅保存在本地的唯一昵称
- 优化 RWID 手机绑定与账户恢复流程
- 将“钱包”Tab 升级为“我的（Profile）”
- 从底部导航移除 AI Tab，将 Aime 调整为可关闭、可再次唤醒的全局浮层助手
- 为 FLON、SING 提供更清晰的实时行情和成交信息
- 以清晰、合规的方式引导用户进入 FullSwap
- 优化 FullOn USDT 通过 FullBridge 跨链的用户体验
- 在所有签名、兑换和跨链操作前明确展示执行方、网络、账户、资产与风险

## 新版信息架构

新版 HuFu 使用固定底部导航，将核心产品功能分为五个一级 Tab：

| Tab | 产品定位 | 主要内容 |
| --- | --- | --- |
| 首页 | 聚合信息与快捷入口 | 当前链和账户、重点功能、推荐 DApp、持仓相关行情、快讯 |
| 社交 | 基于钱包身份的 Web3 社交入口 | 1:1 聊天、群聊、聊天室工具、最近访问的 DApp |
| 市场 | 数字资产行情与资讯入口 | 主流币及生态币价格、走势图、成交信息、市场快讯 |
| 发现 | 多链 DApp 导航入口 | FullOn 及其他知名公链的生态应用 |
| 我的 | 账户、钱包与个人设置 | Profile、多链资产、安全恢复、DApp 记录、Aime 设置 |

## 首页

首页是用户打开 HuFu 后的默认落点，用于快速确认当前链和账户，并发现最重要的功能、DApp、行情和资讯。

### 页面模块

| 区域 | 内容 | 关键交互 |
| --- | --- | --- |
| 顶部账户栏 | 当前公链、本地钱包昵称、账户名、缩略地址 | 切换网络、切换账户、复制地址、查看账户详情 |
| 顶部海报 | 重点功能、生态活动、重点推荐 DApp | 进入功能介绍或 DApp 详情，不直接触发签名 |
| 快捷功能 | 收款、转账、账户恢复、常用功能 | 进入对应的明确操作流程 |
| 推荐 DApp | 与当前网络或运营重点相关的应用 | 查看介绍、所属网络和域名后打开 DApp |
| 持仓相关行情 | 用户钱包持有币种的价格与涨跌 | 进入币种行情详情或发现相关 DApp |
| 快讯 | 市场快讯、FullOn 生态动态 | 查看来源、发布时间和快讯详情 |

### 当前链与账户

首页顶部必须持续展示当前公链和账户信息，防止用户在错误网络或错误账户下操作：

- 展示网络名称和图标，例如 FullOn、Ethereum 或 Solana
- 优先展示用户设置的本地钱包昵称
- 同时保留链上账户名和缩略地址，用于核对真实账户
- 地址支持一键复制，完整地址可在账户详情中查看
- 点击网络打开网络切换面板
- 点击账户切换账户或进入“我的”查看完整信息
- 切换网络后，DApp、行情、资产符号和后续签名上下文同步更新
- DApp 需要其他网络时，先解释原因，再请求用户确认切换

### 海报与重点 DApp

顶部海报支持轮播，但首屏只保留少量高优先级内容。推荐内容包括：

- HuFu 钱包初始化、RWID 恢复等核心功能
- FullSwap、FullBridge 等重点 DApp
- FullOn Network 的重要生态应用
- 新功能、生态活动和安全提醒

海报和推荐卡片需要显示 DApp 名称、所属网络和功能类型。点击后先进入详情或跳转确认页，不能直接连接钱包、授权、签名或交易。

### 持仓相关行情

首页行情根据当前本地钱包状态排序：

- 用户持有某个币种时，优先展示该币种的价格、涨跌幅和所属网络
- 用户持有 FLON 或 SING 时，优先展示相应实时行情及 FullSwap 市场入口
- 没有相关持仓时，展示 FLON、SING 和主流币的默认行情
- 切换账户或网络后，行情排序随当前上下文更新
- “持仓相关”只表示信息排序，不使用“建议买入”等投资诱导措辞

持仓读取和个性化处理应尽可能在本地完成。需要上传或分析钱包数据时，必须说明用途并取得用户同意。

### 首页状态

| 用户状态 | 首页主要内容 |
| --- | --- |
| 尚未创建钱包 | 创建钱包、导入钱包、通过 RWID 恢复账户的主要入口 |
| 已有钱包但无资产 | 当前账户、收款入口、基础行情、入门 DApp 和安全提示 |
| 已有钱包和资产 | 当前链与账户、持仓相关行情、常用 DApp、快讯 |
| 行情或快讯加载失败 | 保留本地钱包功能，单独提示模块失败并允许重试 |

## 社交

用户通过本地钱包签名，以钱包身份登录 HuFu 社交服务，并建立与钱包账户名对应的社交账户。

社交 Tab 包括：

- 用户搜索与会话列表
- 一对一聊天
- 创建、加入和管理群聊
- 消息、未读状态及会话置顶
- 聊天室工具面板
- 数字红包等 Web3 互动工具
- 曾经访问过的 DApp 卡片，便于快速再次打开

钱包的本地昵称仅用于当前设备区分钱包用途，不作为社交昵称，也不会替代链上账户名或地址。

聊天消息不能静默触发红包、转账或 DApp 资产操作。所有资产操作必须由用户确认并调用本地钱包签名。

## 市场

市场 Tab 用于展示主流数字货币和 FullOn 平台生态币的公开行情，包括：

- 主流币价格与涨跌幅
- FLON、SING 等生态币行情
- 分时及不同周期的价格走势图
- 交易对、最新成交价和近期成交记录
- 市场快讯与生态动态

行情详情可以提供 FullSwap 的发现入口，但应由用户主动确认后进入 DApp，不在 HuFu 行情页面内直接完成交易撮合。

## 发现

发现 Tab 汇集 FullOn Network 及多条知名公链的生态应用入口。用户可以按公链或应用类型浏览 DApp，包括：

- FullOn Network
- Bitcoin
- Ethereum
- Solana
- BNB Smart Chain
- Tron Network
- 其他受支持网络

DApp 类型包括数字红包、跨链、借贷、质押、锁仓、交易、RWA 等。每个入口应展示 DApp 名称、所属网络、功能简介和目标域名，并在打开前向用户确认。

## 我的（Profile）

原“钱包”Tab 更名为“我的（Profile）”。钱包能力不会移除，而是与个人账户、安全恢复、使用记录和应用设置统一管理。

| 模块 | 主要内容 |
| --- | --- |
| Profile 账户卡 | 头像、本地钱包昵称、账户名、当前网络、缩略地址、二维码与地址复制 |
| 钱包与资产 | 多链钱包、账户切换、本地昵称管理、资产总览、收款、转账、交易记录和代币管理 |
| 身份与安全 | 私钥/助记词安全入口、RWID 手机绑定、公钥换绑、账户恢复和安全提醒 |
| DApp 管理 | 最近访问、收藏、已连接的 DApp 与授权管理 |
| Aime | 唤醒 Aime、显示浮层开关、通知与隐私设置、清除对话记录 |
| 通用设置 | 语言、货币单位、网络、主题、通知、帮助、关于与版本信息 |

多链钱包支持 FullOn、BTC、ETH、SOL、BNB/BSC、TRX 及其他受支持网络。

涉及私钥、助记词、RWID 或 DApp 授权的入口进入独立安全页面，不能与普通偏好设置混放或通过一次误触直接执行。

### 本地钱包昵称

每个钱包账户都可以设置一个当前设备内唯一的本地昵称，用于区分钱包用途，例如“日常钱包”“储蓄钱包”或“工作钱包”。

- 昵称仅保存在 HuFu 当前设备的本地安全存储中
- 同一设备上的不同钱包账户不能使用相同昵称
- 创建或导入钱包时可以设置，也可以稍后在账户详情中修改
- 未设置时由 App 显示可区分的默认名称
- 账户切换器、首页账户栏和“我的”页面统一展示该昵称
- 昵称不会写入区块链，也不会上传到社交服务
- 修改昵称不会改变账户名、地址、公私钥、资产或交易记录
- 在其他设备恢复或导入钱包时，本地昵称不会自动恢复

转账、授权、签名、兑换和跨链确认页面仍需同时展示公链名称与缩略地址，不能只凭昵称确认敏感操作。

## 全局 Aime 浮层

Aime 不再占用底部 Tab，而是作为全局智能助手出现在首页、社交、市场、发现和“我的”等主要页面。

### 展示形态

- 默认以小型悬浮按钮显示，不遮挡底部导航和主要操作按钮
- 点击后以半屏对话面板打开，并可展开为完整对话页
- 支持最小化、移动到安全区域或关闭
- 键盘弹出、交易确认或全屏 DApp 页面中自动避让或暂时收起
- 关闭后保留用户选择，不在页面切换时自动重新出现
- 用户可以在“我的 > Aime”中再次唤醒并重新开启全局浮层

### 功能范围

Aime 可以：

- 回答 FullOn Network Protocol 相关问题
- 介绍 FullOn 公链的 DApp 应用生态
- 解答常见 Web3、钱包和多链使用问题
- 结合当前页面解释功能，但读取敏感信息前必须获得授权
- 根据用户需求推荐合适的 DApp
- 在用户确认后引导进入相应 DApp

Aime 可以准备操作路径或参数，但不能代替用户连接钱包、授权、签名、兑换、转账或跨链。

## 关键用户流程

### 创建钱包与账户

1. 创建本地自托管钱包
2. 生成钱包密钥与 FullOn 账户
3. 为钱包设置当前设备内唯一的本地昵称（可跳过）
4. 完成必要的安全确认
5. 选择是否通过 RWID 绑定手机号
6. 进入 HuFu 首页

界面需要明确提示：私钥和助记词由用户自行保管，HuFu 不应代替用户保存或索取这些敏感信息。

### 通过 RWID 恢复账户控制权

1. 在新设备上生成一组新的本地密钥
2. 输入已绑定 RWID 的手机号
3. 完成短信验证码校验
4. 授权将账户换绑至新的公钥
5. 重新获得对原账户及链上资产的控制权
6. 为该钱包重新设置仅保存在新设备上的本地昵称

该流程恢复的是账户控制权，不会找回或导出已经丢失的旧私钥。

为降低短信劫持、SIM 卡换绑和恶意重试风险，正式实现还应配合验证码频率限制、异常设备识别、换绑冷静期、旧设备通知或其他增强验证机制。

### 查看 FLON 与 SING 行情

除主流数字货币行情外，市场模块和首页持仓相关行情重点展示：

- FLON、SING 实时市场价格
- FLON/USDT、SING/USDT 等相关市场
- 最新成交价和近期成交记录
- 价格变化、成交时间及交易对信息

FLON 与 SING 的相关流动性市场部署在 FullOn 公链的 FullSwap DApp 中。HuFu 展示公开行情和链上成交数据，不直接提供交易撮合或资产托管服务。

### 发现并进入 FullSwap

用户希望兑换 FLON、SING 或 FullOn USDT 时，HuFu 通过首页、发现、搜索、Aime 推荐或行情详情帮助用户找到 FullSwap。

- 使用“查看 FullSwap 市场”或“前往 FullSwap”等中性入口
- 跳转前展示 DApp、访问地址、当前网络和风险提示
- 用户主动确认进入 FullSwap
- 钱包连接、参数确认和交易签名均由用户主动完成
- 明确标识兑换操作由 FullSwap 智能合约执行

FullSwap 官方入口：[https://fullswap.flon.network](https://fullswap.flon.network)

### 通过 FullBridge 跨链

用户在 FullSwap 兑换获得的 USDT 发行于 FullOn 公链。需要将资产转移至其他受支持网络时，可以通过 FullBridge 发起跨链操作。

界面需要展示：

- 当前资产及所在网络
- 目标网络与接收地址
- 跨链数量、网络费用和预计到账数量
- FullBridge 执行状态和链上交易记录
- 失败、超时或资产不受支持时的处理提示

实际支持的网络、资产、额度、费用和完成时间，以 FullBridge 当前支持范围及链上状态为准。

FullBridge 官方入口：[https://fullbridge.flon.network](https://fullbridge.flon.network)

## 跨模块体验

- 首页海报、推荐 DApp、行情和快讯分别进入对应详情页
- 社交红包或 DApp 卡片进入钱包确认页或相应 DApp
- 市场中的 FLON、SING 行情可以引导用户发现 FullSwap
- Aime 在任何主要页面中都可以打开对应的 DApp 详情页
- 发现页打开 DApp 后，所有资产操作统一调用钱包确认和签名
- “我的”统一承载钱包、账户、安全、Aime 和应用设置
- 每个 Tab 保留自己的滚动位置和页面状态
- 从 DApp 返回 HuFu 时，回到原来的首页、会话、行情或推荐上下文

## 安全与合规边界

- HuFu 作为自托管钱包，不替用户保管助记词或私钥
- 行情与持仓相关排序属于信息展示，不构成投资建议
- HuFu 不在行情页面内直接提供交易撮合或资产托管服务
- DApp 访问前展示名称、域名、网络和风险，用户主动确认后进入
- 钱包连接、授权、签名、兑换、转账和跨链均需用户明确确认
- 手机号和短信验证码属于高敏感账户凭证，需要防范 SIM 卡劫持、验证码泄露、钓鱼和恶意换绑
