# Hufu Wallet UI 设计规范

> 本文件是项目 HTML 高保真设计稿与后续 Flutter 页面设计的唯一事实来源。生成或修改页面前必须完整读取。

## 1. 产品与设计定位

- 产品：多链 Web3 自托管钱包，包含资产、市场、DApp、社交与 Aime 智能助手。
- 目标平台：iOS / Android 竖屏移动端。
- 技术载体：HTML/CSS 高保真设计稿；后续映射 Flutter。
- 设计基准：Flutter `390 × 844`；HTML 固定 `750px` 画布（换算系数 k = 1.923）。
- 界面语言：中文为当前演示语言，结构必须支持国际化长文案。
- 品牌气质：安全、可信、专业、开放、清爽金融科技。

## 2. 核心原则

1. 资产、金额、网络、地址和风险信息优先。
2. 品牌蓝用于主操作与核心资产区域；首页使用浅灰分组背景和白色卡片，社交、市场、发现、我的保持白色页面背景。
3. 涨跌、成功和风险不能只依赖颜色表达。
4. 所有触控目标至少 `44 × 44px`，固定操作避让系统安全区。
5. 页面使用单一移动画布，不使用“设计说明 + 设备模型”的桌面展示布局。
6. UI/UX 只重做原型已有内容的视觉层级，不新增原型未定义的业务模块、数据或入口。

## 4. 字体与排版

- 标题与正文：Manrope；中文回退 PingFang SC / Noto Sans CJK。
- 金额、行情、Gas 与百分比：DIN，启用等宽数字。
- 字号层级：金额 `24–34px`，页面标题 `18–24px`，区块标题 `16px`，正文 `14px`，说明 `12–13px`，导航 `10px`。
- 长地址采用中间省略；金额和关键按钮不得因字体缩放被截断。

## 5. 间距与尺寸

采用 `4px` 最小单位与 `8px` 主节奏：`4 / 8 / 12 / 16 / 20 / 24 / 32px`。

- 页面左右安全边距：`16px`。
- 标准卡片内边距：`16px`。
- 模块间距：`24px`。
- 列表行高：至少 `48px`，推荐 `52–56px`。
- 触控区域：至少 `44 × 44px`。

## 6. 圆角、边框与投影

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-sm` | `8px` | 小按钮、标签 |
| `radius-md` | `10px` | 输入、普通按钮 |
| `radius-lg` | `12px` | 标准卡片、弹层内部 |
| `radius-xl` | `16px` | 大卡片、底部面板 |
| `radius-2xl` | `20px` | 快捷操作卡 |
| `radius-hero` | `32px` | 资产主卡 |
| `radius-pill` | `999px` | 胶囊标签 |

普通卡片优先使用细边框和留白；轻投影仅用于重点卡片，悬浮投影仅用于 FAB，禁止重黑阴影。

## 7. 核心组件

- AppBar：位于画布滚动容器内，`position: sticky`，高度约 `56px + safe-area`。
- 底部导航：五等分，`56px + safe-area`，激活项品牌蓝，固定并锚定画布。正式图标统一存放在 `docs/uiux/v1/assets/images/navigation/`，采用 `24 × 24` SVG，并为每项提供默认态与 `-active` 激活态图片；HTML 必须使用标准 `<img>` 加载，确保 HTTP 与 `file://` 直接打开均可显示。Flutter 端可复用同一图形并通过主题色着色。首页使用“房屋轮廓 + HuFu 双曲线”的品牌化图形，其余导航保持通用语义并统一圆角线帽、`1.8–2.2px` 视觉线宽和留白。
- 资产主卡：网络 / 钱包 → 地址 → 总资产 → 法币折算，圆角 `24–32px`。
- 快捷操作：转账、收款、记录、扫一扫采用四列等宽的上图下文布局，不使用按钮底色；图标采用 `36–44px` 主题主蓝单层图标底，白色图形反显，文字居中显示。首页轮播与快捷操作组合卡采用紧凑布局，轮播约 `2.16:1`，快捷按钮高度不低于 `72px`。
- 按钮：主按钮高 `48px`，品牌蓝背景，无额外投影；文字按钮仍需 `44px` 点击区。
- 输入：高 `48px`，`1px` 边框，聚焦品牌蓝，错误危险红。
- 列表：币种图标 `36–40px`，名称左对齐，价格和涨跌右对齐。
- 底部面板：仅覆盖画布，顶部圆角 `16px`，底部延伸到安全区。
- 反馈：Toast 仅用于轻反馈；重要资产操作需明确结果与风险信息。

## 8. 页面模式

- 首页：网络与当前钱包、FullBridge 重点推荐、四项快捷操作、探索生态、持仓行情和市场快讯。
- 社交：白色页面背景，身份、搜索、联系人、会话与资产安全说明。
- 市场：白色页面背景，核心行情、周期、统计和行情列表，数据装饰必须克制。
- 发现：白色页面背景，顶部为 `56px` 搜索栏与 `56px` 最近访问；其下是吸顶双层筛选，第一行公链高 `38px`、链按钮高 `36px`、字号 `11px`，第二行分类高 `44px`、字号 `12px`。两行均左对齐紧凑横向滚动，公链不提供“全部”，分类保留接口原文“全部 / All Dapps”。默认选择 FLON 与“全部”；全部分类下双列错落卡片不显示右上角 Tag，选择具体分类后才显示对应 Tag，核验状态始终位于卡片内容底部。
- 我的：白色页面背景，钱包摘要、安全、管理和 Aime 设置。

## 9. 图标与图片

- 复用 Hufu 品牌素材、项目 SVG 图标和链官方图标。
- 常规图标 `24px`，辅助图标 `16–20px`，快捷入口 `32–40px`。
- 社交抽屉操作图标统一存放在 `docs/uiux/v1/assets/images/social/`，使用 `24 × 24` 品牌蓝 SVG 图片、透明背景，图标与文字保持紧凑的 `8px` 布局间距。
- 禁止 Emoji 充当功能图标；图片保持比例并提供替代文本。

## 10. 动效与状态

- 点击反馈 `100–150ms`；页面与面板切换 `180–250ms`。
- 优先动画 `opacity` 与 `transform`，避免宽高动画造成抖动。
- 支持 `prefers-reduced-motion`，关闭循环漂浮和大范围位移。
- 页面需覆盖正常、加载、空、错误、禁用和成功状态。

## 11. HTML 固定画布

平台标记为 `mobile`。画布宽度必须是固定 Token，禁止把 `--canvas-w` 写成 `100%`。

```css
:root {
  --canvas-w: 375px;
  --canvas-inset: 0px;
}

#app-frame {
  width: 100%;
  max-width: var(--canvas-w);
  min-height: 100dvh;
  margin: 0 auto;
}

.canvas-fixed {
  position: fixed;
  left: var(--canvas-inset);
  right: var(--canvas-inset);
  width: auto;
  transform: none;
}
```

强制规则：

1. 画布物理宽度固定 `375px`（`--canvas-w: 375px`，移动端屏幕宽度），不随窗口缩放铺满；内部按 `750px` 设计稿布局（`#app-frame` 布局宽 750px），运行时由 JS 计算缩放比例 `s = min(视口宽, 375px) / 750`（`transform: scale(s)` + 高度补偿，窗口高 >812px 时画布物理高 812px 垂直居中）；底部导航、遮罩、底部面板、FAB、Toast、启动页等覆盖层均为画布内锚定（absolute + `--canvas-inset: 0`），随画布统一缩放，与内容比例一致。
2. AppBar 使用 sticky 并留在 `#app-frame` 内。
3. 底部导航、遮罩、底部面板和 FAB 均锚定 `--canvas-inset`。
4. FAB 使用 `right: calc(var(--canvas-inset) + 31px)`。
5. 固定底部区域添加 `env(safe-area-inset-bottom)`。
6. 不使用媒体查询改变画布宽度。
7. 宽度断点按“等效画布宽度”重映射：新断点 = 750 × 旧断点 / 420（如 359→640、380→680、340→610），缩放断点固定 749px。

## 12. 可访问性与安全

- 正文对比度至少 `4.5:1`；图标按钮提供 `aria-label`。
- 状态不只依赖颜色；TalkBack / VoiceOver 顺序与视觉顺序一致。
- 私钥、助记词和敏感信息默认遮挡。
- 交易不可逆操作必须二次确认，并明确网络、对象、资产、金额、Gas 与风险。

## 13. 验收清单

- [ ] 主色、字体、间距和圆角符合 Token。
- [ ] 点击区域不小于 `85 × 85px`（44px × 1.923 取整）。
- [ ] 无 Emoji 功能图标、Lorem Ipsum、重阴影和无依据的新主色。
- [ ] 1500px 宽屏下画布固定 375px 居中，内容完整，导航、遮罩和底部面板与画布边缘完全重合。
- [ ] 390px 窄屏下画布收缩为视口宽，内容经比例缩放后完整显示、无横向滚动。
- [ ] 图片资源无 404，控制台无 JavaScript 错误。
